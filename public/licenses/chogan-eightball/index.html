The game runs from files served by Denny Games inside an allow-scripts-only opaque-origin frame. Its CSP blocks network requests, nested frames, forms and workers. The host bridge pauses animation, translates controls and localizes the game interface; the host removes the upstream back/fullscreen exits, share links and currency rewards. Each new match racks a fresh table; progress and records are not kept after leaving or reloading.
