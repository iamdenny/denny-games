The host removes the upstream ad, analytics, social popup, and score reporting requests. It adds a restricted local save bridge, pause and resume, large touch controls, and bilingual in-game labels. The game runs in an opaque-origin sandbox with external connections blocked.

Runtime dependencies: jQuery 1.9.1 and JavaScript Cookie 2.0.0-pre (MIT), and Keypress 1.0.8 (Apache-2.0). The upstream JSONfn is not bundled; the host uses a JSON-only serializer and restores game instances through their constructors. See MIT dependency notices and Apache License 2.0.
