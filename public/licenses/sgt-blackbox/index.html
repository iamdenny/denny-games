Pinned upstream source commit · Official Black Box browser build · Source and runtime hashes

The official HTML, JavaScript and WebAssembly were checked by SHA-256 and are inlined into a local opaque-origin frame. The local adapter injects the checked WebAssembly bytes to block runtime fetches, keeps upstream preferences in frame memory, gates input and animation while paused, and maps touch taps to the original right-click marking action. Puzzle progress is not saved.
