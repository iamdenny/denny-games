# English and Korean

## Status

Accepted — 2026-10-11.

## Context

English/Korean browser arcade with free static hosting, expandable game inventory and advertising requirements. Later user decisions take precedence over the research draft.

## Decision

Only en and ko. Every localized route has a matching alternate and self canonical. The root is x-default. Play/search/diagnostic/personal routes are noindex.

## Consequences

Two complete translation surfaces; no automatic unreviewed language variants.

## Verification

Owning modules and release checks are mapped in [PRD](../product/PRD.md) and [testing](../testing.md).
