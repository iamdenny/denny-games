# Registry and catalogue scale

## Status

Accepted — 2026-10-11.

## Context

English/Korean browser arcade with free static hosting, expandable game inventory and advertising requirements. Later user decisions take precedence over the research draft.

## Decision

Typed registry drives every card/detail/category/search/sitemap route. Paginate 24 entries with independent canonicals. Keep 1,000 synthetic fixtures private to tests.

## Consequences

No page copying or inflated game counts; category tags and input evidence are separate.

## Verification

Owning modules and release checks are mapped in [PRD](../product/PRD.md) and [testing](../testing.md).
