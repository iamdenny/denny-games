# Evidence and release

## Status

Accepted — 2026-10-11.

## Context

English/Korean browser arcade with free static hosting, expandable game inventory and advertising requirements. Later user decisions take precedence over the research draft.

## Decision

Require types, rules tests, docs, 1,000-entry scale, artifact and browser checks. Merge passing PRs, deploy exact main SHA, verify public release SHA and TLS independently.

## Consequences

Do not equate automation, actual mobile/pad/Tesla tests, indexing, advertising approval or revenue.

## Verification

Owning modules and release checks are mapped in [PRD](../product/PRD.md) and [testing](../testing.md).
