# Original classic-rule logic games

Status: Accepted · 2026-10-22

## Context

The local catalogue already has 207 games. Adding more outbound links would conflict with ADR 0038. The next increment should offer complete, repeatable play with a small download and clear controls.

## Decision

Add Lantern Grid (cross-toggle lights) and Number Trail (sliding numbers) as original TypeScript implementations. Each has 24 seeded stages, generated by legal moves from the completed board. Lantern Grid grows from 3×3 through 4×4 to 5×5; Number Trail grows from 3×3 to 4×4. A longer shuffle is not a shortest-solution or strictly increasing difficulty claim.

Share a lazy-loaded DOM renderer and pure rules module. Support pointer, keyboard and the existing gamepad action contract, with bilingual instructions. Use original SVG illustrations and CSS shapes; copy no branded characters, source, levels, music or graphics. These project-authored files use the repository MIT license.

Save a seed/stage identity, validated action history and total move count through the existing local save contract. Invalid histories reset to the generated board. Undo reverses board state without refunding moves. Cap saved history at 2,000 actions and display a localized recovery message at the limit. Scores start at 1,000 and decrease by five per move, with a floor of zero. No timer or server account is introduced.

Feature both games in editorial discovery and the point-and-play collection. Preserve the six different genres in the first six home picks; place these additions immediately after that group. Keep daily challenges restricted to the existing three games; no new streak or ranking claim.

## Consequences

The local catalogue reaches 209 entries. Small, independently testable rules make correctness easier to check. Generated solvability does not mean every player will find every solution, and does not guarantee unique boards across all seeds. Actual gamepad and physical mobile-device verification remains pending.

## Verification

Unit tests replay known solutions across all 24 stages and four seeds per game, check boundaries, legal moves, determinism and saved-history validation. Browser tests exercise bilingual completion, next-stage navigation, undo, pause, reload, restart, keyboard operation and corrupt-save recovery, plus 320/360/390/430/1440px layouts and emulated touch input. Run the repository verification and browser suites before merge. These are browser/simulation checks, not physical-device evidence.
