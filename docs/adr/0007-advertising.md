# Advertising and consent gates

## Status

Accepted — 2026-10-11.

## Context

English/Korean browser arcade with free static hosting, expandable game inventory and advertising requirements. Later user decisions take precedence over the research draft.

## Decision

Build manual display slots and H5 boundaries now. Default off. Live requests require configured IDs, separate approvals, certified CMP signal and hosting suitability.

## Consequences

Ads are implemented but not represented as approved/serving. No homemade consent checkbox substitutes for CMP.

## Verification

Owning modules and release checks are mapped in [PRD](../product/PRD.md) and [testing](../testing.md).
