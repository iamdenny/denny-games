# Hextris responsive arcade import

## Delivered

- Add Hextris as the 202nd playable title in arcade, with English/Korean rules, controls, tips, search tags and original Denny Games artwork.
- Pin upstream revision `3f4847dc8fd7dab3d1c87e6324b9159d92fbd396`, hash every upstream file and publish GPL-3.0-or-later and dependency notices.
- Remove advertising, analytics, social popups and the upstream external score-reporting request from the served runtime.
- Add a no-network opaque-origin iframe, bounded local storage, host pause/resume/restart, keyboard/gamepad mapping and large labeled left/right touch buttons.
- Checkpoint the board and score during play; confirm capture and browser-storage writes before English/Korean switching, and stay on the page with a save error when persistence fails.

## Evidence boundary

Chromium coverage is automated evidence for the browser contract, not for physical phones/controllers, Tesla, user preference, GitHub-to-player conversion or revenue. GitHub stars are a repository-interest signal and do not measure players. Production release remains open until CI, review, deployment SHA and public URL readback pass.
