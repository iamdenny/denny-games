# 다음 릴리스 PRD

## 해결할 문제

2026-10-12 기준 6개 카테고리에 194개 게임이 있었지만, 모두 터치·키보드·게임패드 입력 표시가 비슷해 원하는 조작 방식의 게임을 고르기 어려웠다. 검색 결과에 장르·조작·길이 필터가 없고, 실물 기기 검증은 아직 없다. 모바일 반응형 검사 통과를 휴대폰·테슬라 지원 완료로 오해하지 않도록 안내와 점검 절차를 연결한다.

## 이번에 개발하고 배포할 범위

| ---------------------- | --------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------- |

게임 모음은 순위나 검증된 추천이 아니라 조작·규칙에 따른 편집 모음이다. 광고는 기존 위치와 승인 게이트를 유지한다. 검색·점검·플레이 화면에는 제휴 카드를 추가하지 않는다. 사이트 UI와 설명은 한·영으로 제공하며 가져온 게임 내부의 원본 영문 문자는 그대로 안내한다.

## 사용자 흐름

홈의 게임 모음 → 조작 방법과 제한 확인 → 게임 상세 → 플레이. 검색에서는 조건을 조합하고 결과 수를 확인한 뒤 페이지를 넘긴다. 기기 지원이 궁금하면 호환성 안내 → 기기 점검 → 실제로 테스트 → 결과 파일 다운로드로 이어진다. 결과는 이 브라우저에서만 처리하며 자동 업로드나 공개 검증 등록은 하지 않는다.

## SEO와 GEO 기준

한 버튼으로 할 게임, 위치를 움직여 조작하는 게임, 숫자 퍼즐, 매일 같은 문제에 도전할 게임이라는 구체적인 질문에 먼저 답한다. 선정 기준·게임별 조작·저장 한계·현재 실기기 검증 상태를 본문에 명시한다. 구조화 데이터는 화면에 표시한 게임과 일치시킨다. 필터 조합과 개인 점검 결과는 색인 대상으로 만들지 않는다. 검색 순위, 색인과 AI 인용은 배포 성공과 구분한다.

근거: [Google AI 검색 안내](https://developers.google.com/search/docs/appearance/ai-features), [Schema.org ItemList](https://schema.org/ItemList), [CollectionPage](https://schema.org/CollectionPage).

## 검증과 배포

단위 검사는 필터 조합, 잘못된 URL 값, 페이지 경계와 모음 등록을 확인한다. 브라우저 검사는 JavaScript 없는 모음 탐색, 필터 유지·초기화·언어 전환·페이지 이동, 320/390px 화면과 점검 파일의 미실행/성공/실패 구분을 확인한다. 기존 게임 회귀 검사를 함께 실행한다. PR CI 통과 후 머지하고 Pages 배포 SHA와 공개 한·영 모음, sitemap, 검색·점검 및 기존 게임 경로를 읽어 확인한다.

Denny Games에서 실행되는 게임은 205개이며 나머지 17개는 외부 호스트에서 열린다. 현재 분포는 퍼즐 34, 아케이드 41, 액션 64, 슈팅 47, 레이싱 13, 스포츠 8, 보드 5, 전략 2, 로그라이크 6, 시뮬레이션 2개다. 이 카운트는 사용자 선호 측정치를 대신하지 않는다.

위 목표는 이번 릴리스의 완료로 처리하지 않는다. 무료 외부 게임 링크를 추가하는 작업과 사이트 안에서 실행되는 게임의 카테고리 공급은 별도로 관리한다. 레이싱·스포츠 후보와 실기기 지원도 계속 살피되, 외부 URL 도달만으로 모바일·컨트롤러 호환성을 주장하지 않는다. 실물 기기 결과는 기기별 실제 조작을 확인해야 확보할 수 있다.

2026-10-15에 Libre Arcade의 공개 브라우저 복원판 23종과 PVP, OpenGlad, Sheepdog Sim 3를 외부 링크 목록에 추가했다. 각 출처·라이선스·호스트를 기록하고, GET으로 열린 페이지까지만 확인했다. 전체 플레이 세션과 기기 호환성은 검증하지 않았다. OpenFront는 자동 요청에서 HTTP 403을 반환해 이번 공개 목록에서 보류했다. 카탈로그는 248개 페이지(사이트 내 실행 205개, 외부 링크 43개)다.

2026-10-16에 A Dark Room, Ancient Beast, MIT 라이선스 OpenGames의 여섯 게임, Blockyard 브라우저 게임 로비를 외부 링크로 추가했다. 각 출처와 라이선스, 호스트 이용 조건을 기록하고 9개 URL의 HTTP 200만 확인했다. 모바일 확인에서 A Dark Room은 390px 폭에서 가로 넘침이 있었고, Ancient Beast는 세로 휴대폰 화면에 가로 회전을 안내했다. Blockyard 로비는 게스트 모드와 임시 진행 저장을 표시했다. 이 검사는 전체 플레이·실물 기기·호스트 계정을 증명하지 않는다. 카탈로그는 257개 페이지(사이트 내 실행 205개, 외부 링크 52개)다.

2026-10-16에 mashukui의 MIT 브라우저 게임 27개, EveryGameMade가 라이선스에 따라 호스팅하는 15개 오픈소스 게임, open-games.org의 GPL 브라우저 게임 5개를 외부 링크로 등록했다. 세 컬렉션의 원본 저장소·라이선스·호스트를 기록했다. 확인한 후보 URL 52개는 모두 HTTP 200을 반환했고, 중복 5개를 제외한 47개를 새로 등록했다. 완전한 플레이 세션은 검사하지 않았다. 게임별 조작 정보는 각 출처의 설명을 따르며, 이 사이트에서 실기기 호환성을 보증하지 않는다. 카탈로그는 304개 페이지(사이트 내 실행 205개, 외부 링크 99개)다.

2026-10-16에 Tessel, EkoScape, Astray 2, YourCraft, Brakeless, hotlapped, LEXTOWN-01과 Mingat Games의 Cozy Cafe 3D, Paws & Play: 3D Pet Daycare, Nomad Life를 추가했다. 타일 퍼즐, WebGL 미로, 복셀 샌드박스, 3D 레이싱과 시뮬레이션을 섞고, 오픈소스 코드와 소스 라이선스 미공개·모든 권리 유보 게임을 구분했다. 새 플레이 URL 10개는 HTTP 200을 반환했다. 저장소·호스트·가격 안내를 각각 확인했으며 전체 게임 세션과 실기기 호환성은 검증하지 않았다. 카탈로그는 314개 페이지(사이트 내 실행 205개, 외부 링크 109개)다.

2026-10-16에 Warzone 2100 Web Edition, 실험용 Mindustry 웹 포트, City Defense, YS Flight Simulator Web, NetCraft를 외부 링크로 추가했다. 실시간 전략, 공장 자동화 방어, 실제 도시 지도 방어, 비행 시뮬레이션, 복셀 샌드박스를 포함한다. 네 프로젝트는 공개 소스 라이선스를 기록했고, City Defense는 소스 라이선스 미공개와 무료 브라우저 접속을 분리해 표시했다. 새 플레이 URL 5개는 HTTP 200을 반환했다. WebAssembly/WebGL 요구사항, 초기 로드 크기, 개인정보 안내와 실험·레거시 상태를 출처에 따라 기록했다. 전체 플레이 세션, 실기기, 컨트롤러와 멀티플레이는 검증하지 않았다. 카탈로그는 319개 페이지(사이트 내 실행 205개, 외부 링크 114개)다.

2026-10-16에 Junk Magnet, wibbly, TeeBrawl, Serpentine과 LittleWarGame을 외부 링크로 더했다. 3D 생존 액션, 카메라 또는 스페이스바 테니스, 2D 멀티플레이 슈터, 3D 스네이크와 실시간 전략을 포함한다. 세 프로젝트는 MIT 또는 MIT/Apache 라이선스를 공개했다. TeeBrawl은 소스 코드를 공개하지 않았으며 자체 추가물과 Teeworlds 에셋에 CC BY-SA 3.0을 안내하지만, 그 범위가 JavaScript 코드까지 포함하는지는 명확하지 않아 오픈소스로 표시하지 않았다. LittleWarGame의 전체 코드 라이선스는 확인되지 않았다. 무료 접속과 계정·채팅·가상 아이템 조건은 코드 라이선스와 별도로 기록했다. 다섯 플레이 URL은 2026-10-16에 HTTP 200을 반환했으며 전체 게임 세션, 채팅 관리, 모바일·태블릿, 멀티플레이, 컨트롤러 및 Tesla 동작은 검증하지 않았다. 카탈로그는 324개 페이지(사이트 내 실행 205개, 외부 링크 119개)다.
