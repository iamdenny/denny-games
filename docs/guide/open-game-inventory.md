Another 47 are 27 games from mashukui's MIT browser collection, 15 licensed games hosted by EveryGameMade, and five GPL games from open-games.org. The previous ten add Tessel, EkoScape, Astray 2, YourCraft, Brakeless, hotlapped, LEXTOWN-01, Cozy Cafe 3D, Paws & Play: 3D Pet Daycare and Nomad Life. The next five add Warzone 2100 Web Edition, the experimental Mindustry web port, City Defense, YS Flight Simulator Web and NetCraft. Another five links add Junk Magnet, wibbly, TeeBrawl, Serpentine and LittleWarGame. The previous visual wave adds 3D.CITY, BlockVerse, ThingsPool and Suroi. This wave adds Match-3D.js, Super Kart 3D.js and Arkanoid-3D for a jewel-matching puzzle, cartoon kart racing and a neon 3D brick breaker. These are external links: no third-party build, game data, or screenshot is bundled, and there is no local /play/{id}/ route. Free browser play does not by itself establish an open-source license. Frozen Bubble 2: Fan Edition is an independent rewrite inspired by the 2002 game, not the original project's official site. Host, source, price evidence, license information, reachability and verification limits are recorded in vendor/external-browser-listings.json.

Each locally hosted import has English/Korean controls, a primary category, a fixed source commit, original notices and self-hosted files. External-link pages instead show the source project's license separately from the browser host and explain that account, controls, compatibility, sessions and saves follow that host. Gameplay and device support remain unverified until tested. Names remain the authors' original English names. In-canvas bitmap text remains upstream English; navigation and instructions are bilingual.

The ten categories are board, puzzle, arcade, action, shooting, racing, sports, strategy, roguelike and simulation. They describe the main interaction, not an assertion that a miniature steering game is a full vehicle simulator. Counts are computed from the registry. No empty categories or placeholder games are published.

## Rights records

- `public/licenses/crisp/`: original three game-bundle notices, runtime MIT and Lodash MIT.
- `vendor/bounceback/provenance.json`: pinned GPL-2.0-or-later source and hashes for Bounce Back, its tile sprite and title-screen image. `public/licenses/bounceback/` provides the full license and corresponding-source links.
- `vendor/underrun/provenance.json`: pinned MIT source and hashes for UNDERRUN's game, level maps and texture; the modified Sonant-X module keeps its separate zlib notice. `public/licenses/underrun/` provides both notices and source links.
- `vendor/hextris/provenance.json`: pinned GPL-3.0-or-later source and hashes for the full Hextris repository snapshot. `public/licenses/hextris/` includes the complete GPL license, MIT dependency notices and the Keypress Apache-2.0 license. The hosted adapter removes upstream ads, analytics, social popups and score reporting.
- vendor/external-browser-listings.json: 126 source-project/host pairs. Direct GET reachability was checked for each; Denny Games does not claim complete gameplay or physical-device compatibility. The latest browser checks found Match-3D touch controls and Super Kart race controls in a 390×844 viewport. Arkanoid-3D's published controls remain mouse/keyboard only. Link-only entries do not change the local import count or the port-required candidate dispositions.
- `vendor/catalogue-review.json`: a disposition for all 294 local-port research entries. Integrated, port-required and rights-or-integration-review are distinct.
- `scripts/build-crisp.mjs`: reproducible, checked runtime hooks. Original game source files are not rewritten.

Chain Drift, Comet Slash and Volt Keeper use their own arcade phases and score tables, so they run in a dedicated restricted cycle frame instead of the shared Crisp mini-game adapter. Their source, sprite and audio hashes are recorded in `vendor/crisp-cycles/provenance.json`; the build rejects changed files, symbolic links and paths outside each game's source directory. A localized on-screen direction pad and action button drive the original key controls. The three score tables live only for the open play page. Browser input is automated; physical phones, controllers and Tesla remain unverified. Other candidates include native/homebrew ports and separately licensed assets. They remain recorded for follow-up rather than offered as broken games or external embeds.

Bounce Back adds a boomerang roguelite with generated rooms, enemy variants, pickups, a shop and a final boss. The original source and sprite are retained under GPL-2.0-or-later; the debug console containing eval is preserved as source but excluded from the hosted runtime. Its touch/gamepad bridge and local progress are automated in Chromium, while physical devices remain unverified.

UNDERRUN adds a three-level WebGL twin-stick shooter. Its MIT source and level/texture images are pinned; modified Sonant-X code has a separate zlib notice, and the composer credit is preserved. The host adds touch movement/aim, standard gamepad movement/fire/aim, sound and pause/resume in a no-network opaque-origin frame. Chromium coverage does not establish physical phone, controller, or Tesla support.

Hextris adds a quick hexagonal block-matching puzzle. The source page includes the corresponding runtime source and dependency licenses. Large labeled rotation buttons supplement the original touch gestures; keyboard and standard gamepad left/right actions share the same mapping. The board and high scores are checkpointed every 500 ms and after rotation or pause. In-site language switching waits for a fresh host-side save; a hard reload restores the latest completed checkpoint. A pinned GitHub star count is only a source-repository signal, never a player count or popularity ranking.

## Player differences

Most imports restart on page reload or language change; the shell saves personal best scores, favorites and recent plays. Hextris is an exception: its latest completed board checkpoint and high scores are restored locally. Imported games do not participate in daily seeded challenges. Optional upstream music/WebGL effects are disabled; the shared sound switch controls simple shell-generated effects where supported. A connected standard controller can move a virtual pointer and hold A; Start and disconnect pause. Mouse/touch remains available after controller use. DIGI10 uses number keys or the on-screen number buttons.

At research time the Hextris repository showed about 2.4k GitHub stars. This is a changing developer-interest signal, not evidence of player counts, demand, search rankings or earnings. Candidate games that fail license, load-size or mobile-UX review remain unpublished as local ports. A separate outbound listing may be added only with a real browser host and a clear external-host notice; it does not imply Denny Games approval of that service. A Dark Room remains excluded as an in-site port because its current official host overflows a phone viewport; it is listed only as an external link with the limitation disclosed. Ancient Beast asks portrait-phone players to rotate to landscape. Both remain external hosts, not claims of Denny Games mobile support.

See [runtime decision](../adr/0009-imported-games.md), [onboarding](game-onboarding.md) and [testing](../testing.md).

Sky Golf keeps its course/stroke counter inside the game and does not use the shell score panel. Imported games have no artificial numbered stages; their stage selector is hidden.

## DANGO CSP arithmetic adaptation

The original DANGO uses `Function` to calculate collected integer expressions. CI exposed a CSP failure when a scoring branch was reached. Its unchanged upstream `main.js` and source hash are retained. The build emits `main.csp.js` with a restricted addition/multiplication parser preserving normal precedence; only DANGO loads that derivative. No eval permission or sandbox privilege is added. A deterministic browser regression executes the scoring branch for ordinary, leading-operator and empty expressions. See `host_adaptations` in the provenance record.
