# Denny Games · 데니 게임즈

Free browser games in English and Korean. Initial infrastructure setup; games are not yet published.

- Site: https://games.iamdenny.com
- English: `/en/`
- 한국어: `/ko/`
- Hosting: GitHub Pages, `main` branch, `/docs` directory

## Development scope

Responsive game catalogue with separately reviewed commercial redistribution rights. Mobile, gamepad, and parked-vehicle browser support require per-game validation. Advertising integration and approval are pending.

Each third-party game must retain its own license, credits, and required corresponding source. This repository currently contains no third-party games.

## DNS

`games.iamdenny.com CNAME iamdenny.github.io`

The GitHub Pages custom domain must be configured before adding DNS. Verify DNS, certificate issuance, HTTPS enforcement, and public page responses separately.
